# SamReMake

[English](README.md) | **简体中文**

基于 [SamRewritten](https://github.com/PaulCombal/SamRewritten) 的 Windows Steam 成就与统计管理工具，提供原生桌面界面、搜索筛选、真实解锁时间排序、单游戏导入／导出和语言设置。

目前是独立开发的预览版本，不是 SamRewritten 官方发布版本，也不隶属于 Valve。

## 快速开始

1. 启动 Steam 桌面客户端，登录需要操作的账号。
2. 完整解压便携包，保持 `engine` 文件夹与 `SteamAchievementManager-Remake.exe` 位于同一目录。
3. 运行 `SteamAchievementManager-Remake.exe`，点击 **Load Steam library／读取 Steam 游戏库**；也可以直接输入 AppID，点击 **Open AppID／打开 AppID**。
4. 选择游戏后，从顶部直接进入“成就”或“统计编辑”。

首次启动默认英文；如果已经保存过语言选择，则继续使用该选择。在**窗口左上方的 Settings → Language／设置 → 语言**中可以切换简体中文。

程序使用普通 Steam 连接，连接某个游戏时，Steam 可能显示账号正在游戏中。

## 各项功能有什么用

### 游戏库与 AppID 输入

- **读取 Steam 游戏库**：获取当前登录账号的游戏和应用列表，不必逐个查找游戏编号。
- **搜索游戏 / AppID**：按游戏名称或 AppID 筛选已经加载的列表。它搜索的是当前列表，不是 Steam 商店。
- **打开 AppID**：通过 Steam 应用编号直接打开指定游戏。例如，商店链接 `/app/105600/` 中的数字就是 AppID。输入编号不会获得游戏所有权，也不能保证该应用提供成就或统计数据。

### 成就列表、搜索与状态筛选

成就表格显示名称、说明、当前锁定状态、Steam 返回的解锁时间，以及可用时的全球解锁比例。

**搜索成就**可以匹配成就名称、说明和成就 API ID；状态下拉框可以选择**全部状态、已解锁、未解锁**。两者可以组合使用，便于查找某一项成就或查看尚未完成的成就。

游戏成就的名称和说明来自游戏数据，与程序界面语言分开；切换程序语言不会自动翻译游戏内容。

### 排序与真实解锁时间

排序下拉框提供以下选项：

| 排序方式 | 适合用途 |
| --- | --- |
| 最新解锁在前 | 查看最近解锁了什么。 |
| 最早解锁在前 | 按 Steam 记录的先后顺序回顾成就。 |
| 名称 A–Z | 按名称快速查找成就。 |
| 全球比例降序 | 比较常见成就与较少玩家解锁的成就。 |

解锁时间只采用 Steam 返回的时间戳，并转换为电脑的本地时区显示。已解锁但没有有效时间的成就显示为“未知”，未解锁成就显示为横线。按时间升序或降序时，未知时间都放在末尾。

程序不会用当前时间或其他日期补造缺失时间。这里显示的是 Steam 当前报告的数据，不能据此证明某项成就最初实际获得的历史时间。

### 解锁与重新锁定选中的成就

在成就表格中按 **Ctrl** 或 **Shift** 多选，点击**解锁选中**或**重新锁定选中**。

程序会预览变更，并在确认后提交。受保护的条目，以及已经处于目标状态的条目会被排除。如果 Steam 拒绝某一项，请刷新查看实际状态。

重新锁定后再解锁，不能保留或重新生成原来的历史解锁时间。

### 刷新、读取进度与取消

**刷新 F5**重新读取当前游戏的成就和统计。底部状态栏会显示当前读取阶段、滚动进度条和已等待秒数。

Steam 没有为这些读取请求提供可靠的完成百分比，所以进度条只表示正在处理，不显示虚构的百分比。**取消读取**可以停止当前读取请求；切换游戏会先取消旧读取，再开始新读取。

普通读取每个请求最多等待 25 秒；成就和统计是两个独立请求。取消读取不会撤销已经完成的写入，正在提交的写入也不会被强制中断。

### 统计编辑

进入**统计编辑**，选择一行，输入新数值，再点击**写入选中统计**。它用于修改游戏公开的整数或浮点统计，例如由游戏定义的计数器。

表格会显示 API ID、当前值和权限限制。程序检查数字格式、受保护字段、仅可增加限制，以及适用时的游戏定义范围。输入小数时请使用英文句点。Steam 仍可能拒绝该数值。

### 单个游戏的导出与导入

- **导出进度**：把当前游戏的成就状态和统计保存为 JSON 文件，便于查看或单独保存进度数据。
- **导入进度**：读取兼容的 JSON 导出文件，**只应用当前选中的 AppID**；导入前会显示确认。

导入和恢复处理的是成就状态、统计数值，不能还原历史解锁时间。受保护字段可能被跳过，或被 Steam 拒绝。

## 设置与本地文件

在窗口左上方的**设置 → 语言**中切换英文和简体中文。语言选择保存在：

```text
%LOCALAPPDATA%/SteamAchievementManager-Remake/language.txt
```

桌面端已移除定时队列、好友回放、挂机、跨游戏批处理和历史恢复，不再自动创建快照或写入审计记录。旧版已经保存的 `history.jsonl` 和 `snapshots/` 文件会保留，不会被删除；单个游戏的 JSON 导入／导出按钮仍可用于手动保存和导入进度文件。

## 构建与测试

需要 Windows、Visual Studio 的 **.NET 桌面开发**工作负载、**.NET Framework 4.8 目标包**、MSVC，以及 **1.95 或更新版本的 Rust stable**。

在仓库根目录的 Developer PowerShell 中运行：

```powershell
.\build-remake.ps1
.\tests\run.ps1
```

便携版输出到 `dist/SteamAchievementManager-Remake`。WPF 前端位于 `desktop/Remake`，仓库根目录的 Rust 源码提供无图形界面的后台引擎，无需子模块。

目前仍是开发预览版。构建和自动测试覆盖时间解析、排序、命令参数、读取取消与超时、语言资源、界面读取状态清理、保留的两个页面导航。真实 Steam 账号上的成就与统计写入仍需要进一步集成验证；自动测试不会修改 Steam 账号。
