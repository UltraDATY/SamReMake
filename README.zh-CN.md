# SamReMake

[English](README.md) | **简体中文**

基于 [SamRewritten](https://github.com/PaulCombal/SamRewritten) 的 Windows Steam 成就与统计管理工具，提供原生桌面界面、搜索筛选、真实解锁时间排序、定时队列、好友时间回放、备份恢复和语言设置。

目前是独立开发的预览版本，不是 SamRewritten 官方发布版本，也不隶属于 Valve。

## 快速开始

1. 启动 Steam 桌面客户端，登录需要操作的账号。
2. 完整解压便携包，保持 `engine` 文件夹与 `SteamAchievementManager-Remake.exe` 位于同一目录。
3. 运行 `SteamAchievementManager-Remake.exe`，点击 **Load Steam library／读取 Steam 游戏库**；也可以直接输入 AppID，点击 **Open AppID／打开 AppID**。
4. 选择游戏后，在“成就”“统计编辑”“定时队列”中操作，或从侧边栏进入“高级工作区”。

首次启动默认英文；如果已经保存过语言选择，则继续使用该选择。在**窗口左上方的 Settings → Language／设置 → 语言**中可以切换简体中文。

程序使用普通 Steam 连接，连接某个游戏时，Steam 可能显示账号正在游戏中。

## 各项功能有什么用

### 游戏库与 AppID 输入

- **读取 Steam 游戏库**：获取当前登录账号的游戏和应用列表，不必逐个查找游戏编号。
- **搜索游戏 / AppID**：按游戏名称或 AppID 筛选已经加载的列表。它搜索的是当前列表，不是 Steam 商店。
- **打开 AppID**：通过 Steam 应用编号直接打开指定游戏。例如，商店链接 `/app/105600/` 中的数字就是 AppID。输入编号不会获得游戏所有权，也不能保证该应用提供成就或统计数据。

### 成就列表、搜索与状态筛选

成就表格显示名称、说明、当前锁定状态、Steam 返回的解锁时间，以及可用时的全球解锁比例。

**搜索成就**可以匹配成就名称、说明和成就 API ID；状态下拉框可以选择**全部状态、已解锁、未解锁**。两者可以组合使用，便于查找某一项成就或查看尚未完成的成就。

游戏成就的名称和说明来自游戏数据，与程序界面语言分开；切换程序语言不会自动翻译游戏内容。

### 排序与真实解锁时间

排序下拉框提供以下选项：

| 排序方式 | 适合用途 |
| --- | --- |
| 最新解锁在前 | 查看最近解锁了什么。 |
| 最早解锁在前 | 按 Steam 记录的先后顺序回顾成就。 |
| 名称 A–Z | 按名称快速查找成就。 |
| 全球比例降序 | 比较常见成就与较少玩家解锁的成就。 |

解锁时间只采用 Steam 返回的时间戳，并转换为电脑的本地时区显示。已解锁但没有有效时间的成就显示为“未知”，未解锁成就显示为横线。按时间升序或降序时，未知时间都放在末尾。

程序不会用当前时间或其他日期补造缺失时间。这里显示的是 Steam 当前报告的数据，不能据此证明某项成就最初实际获得的历史时间。

### 解锁与重新锁定选中的成就

在成就表格中按 **Ctrl** 或 **Shift** 多选，点击**解锁选中**或**重新锁定选中**。

程序会预览变更、保存快照，并在确认后提交。受保护的条目，以及已经处于目标状态的条目会被排除。如果 Steam 拒绝某一项，请刷新查看实际状态。

重新锁定后再解锁，不能保留或重新生成原来的历史解锁时间。

### 刷新、读取进度与取消

**刷新 F5**重新读取当前游戏的成就和统计。底部状态栏会显示当前读取阶段、滚动进度条和已等待秒数。

Steam 没有为这些读取请求提供可靠的完成百分比，所以进度条只表示正在处理，不显示虚构的百分比。**取消读取**可以停止当前读取请求；切换游戏会先取消旧读取，再开始新读取。

普通读取每个请求最多等待 25 秒；高级工作区的好友时间线读取最多等待 45 秒，多游戏导出最多等待 120 秒。成就和统计是两个独立请求。取消读取不会撤销已经完成的写入，正在提交的写入也不会被强制中断。

### 统计编辑

进入**统计编辑**，选择一行，输入新数值，再点击**写入选中统计**。它用于修改游戏公开的整数或浮点统计，例如由游戏定义的计数器。

表格会显示 API ID、当前值和权限限制。程序检查数字格式、受保护字段、仅可增加限制，以及适用时的游戏定义范围。输入小数时请使用英文句点。提交前会保存快照，但 Steam 仍可能拒绝该数值。

### 单个游戏的导出与导入

- **导出进度**：把当前游戏的成就状态和统计保存为 JSON 文件，便于查看或单独保存进度数据。
- **导入进度**：读取兼容的 JSON 导出文件，**只应用当前选中的 AppID**；导入前会显示确认并保存快照。

导入和恢复处理的是成就状态、统计数值，不能还原历史解锁时间。受保护字段可能被跳过，或被 Steam 拒绝。

### 按固定间隔定时解锁

先在成就表格中选择未解锁条目，再进入**定时队列**，设置 **1–86400 秒**的间隔，点击**预览并启动**。

队列在第一项执行前也会等待，之后每次等待指定间隔，再逐项提交解锁请求。适合把一组操作分散到一段时间内执行。Steam 请求本身也需要时间，因此间隔不是精确的实际完成时间保证。

**停止后续任务**会取消还未执行的条目，已经提交中的请求仍可能完成。遇到失败时，后续条目会停止。执行期间需要保持程序运行；关闭后不会自动恢复队列，也不会自动补执行错过的任务。切换游戏或刷新前需要先停止队列。

## 高级工作区

侧边栏打开的是 **Remake 内部的附加窗口**，不会再打开 SamRewritten 图形界面。Steam 通信由随包附带的后台引擎处理。

### 跨游戏批处理

在**跨游戏批处理**中输入多个 AppID，用空格或逗号分隔。

| 操作 | 具体作用 |
| --- | --- |
| 导出这些游戏 | 将输入的多个 AppID 导出到一个 JSON 文件。 |
| 导入备份文件 | 导入所选 JSON 文件中包含的游戏。目标游戏由文件内容决定，AppID 输入框不会筛选这项操作。 |
| 解锁全部成就 | 对输入的每个应用提交全部成就解锁请求，仍受 Steam 权限限制。 |
| 重置成就及统计 | 同时重置输入应用的成就与统计，范围比“重新锁定选中成就”更大。 |

写入前需要确认，并会先保存快照。跨游戏操作不是一个整体事务：中途失败或取消时，前面的游戏可能已经处理完成。取消只停止后续工作，不会回滚已完成的请求。

### 好友时间线与相对时间回放

先在主界面选择目标游戏，再进入**好友时间回放**。

1. 点击**读取好友**并选择一位好友，或者直接输入 SteamID64。
2. 设置 **1–10080 分钟**的回放总时长。
3. 点击**读取并预览时间线**，查看符合条件的成就与相对等待时间。
4. 检查计划后，点击**启动预览计划**。

它按照另一位用户已知解锁时间之间的**相对间隔**安排操作，并按你设置的总时长缩放。当前账号已经解锁的成就、受保护条目，以及来源时间未知的条目会被排除。当前登录账号必须能够读取来源用户的成就数据。

第一项没有初始等待；来源时间相同的成就之间没有时间间隔；如果只有一项符合条件，会立即开始。实际请求耗时可能延长运行时间。Steam 会记录本次执行产生的新解锁时间，**不会把好友的历史日期复制到你的账号中**。

### 挂机

**挂机 → 开始挂机**会让当前 AppID 保持游戏中连接，而不启动游戏本身的可执行程序。它不会自行解锁成就。

点击**停止挂机**可以请求正常退出。关闭高级工作区也会请求停止挂机；如果 Steam 响应较慢，需要等待清理完成。强制结束进程或关闭 Windows 时，不能保证正常退出流程仍然完成。

### 历史、快照与恢复

**历史与恢复**列出进度变更前保存的快照，每条记录包含时间、AppID 和备份原因。

选中记录后点击**恢复选中快照**，可以导入该游戏之前的成就状态和统计数值。恢复需要确认，并且会先为当前状态再保存一份快照。如果必要的备份失败，对应的写入不会提交。

快照无法还原成就原来的解锁时间。加入快照功能之前的旧操作可能只存在于文字审计日志中，没有可恢复的快照。

## 设置与本地文件

**设置 → 语言**用于在英文和简体中文之间切换，并记住选择。切换后重新打开高级工作区，其标签会使用新语言。

用户数据保存在：

```text
%LOCALAPPDATA%/SteamAchievementManager-Remake/
├── language.txt       保存的界面语言
├── history.jsonl      主工作区变更的审计记录
└── snapshots/         进度 JSON 文件和快照元数据
```

这些是本地用户数据，不属于源码仓库。更换电脑时，需要自行保留希望继续使用的快照副本。

## 构建与测试

需要 Windows、Visual Studio 的 **.NET 桌面开发**工作负载、**.NET Framework 4.8 目标包**、MSVC，以及 **1.95 或更新版本的 Rust stable**。

在仓库根目录的 Developer PowerShell 中运行：

```powershell
.\build-remake.ps1
.\tests\run.ps1
```

便携版输出到 `dist/SteamAchievementManager-Remake`。WPF 前端位于 `desktop/Remake`，仓库根目录的 Rust 源码提供无图形界面的后台引擎，无需子模块。

目前仍是开发预览版。构建和自动测试覆盖时间解析、排序、命令参数、读取取消与超时、语言资源、界面读取状态清理、串行队列和好友回放计划。真实 Steam 账号上的成就与统计写入、好友访问和挂机仍需要进一步集成验证；自动测试不会修改 Steam 账号。
